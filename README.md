# dark-nodemix
THE lightweight dark mode extension! (Because dark mode shouldn't make a memory leak!)

## Build instructions

```
./build.sh
```

## What the build script does.

* zips
* moves to crx

Literally the only reason it's there is for Mozilla compliance.

## Tested platforms

Fedora 44 Silverblue, see manifest.json for bare minimum version (However, I recommend anything over 124.)
