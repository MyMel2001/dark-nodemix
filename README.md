# dark-nodemix
THE lightweight dark mode extension! (Because dark mode shouldn't make a memory leak!)

## Build instructions

Run this in a new terminal in the cloned folder:

```
bash build.sh
```

## What the build script does.

* zips
* moves to crx

Literally the only reason it's there is for Mozilla compliance in case I ever need it. Prepare for the worst, yk?

## Tested platforms

Fedora 44 Silverblue, see manifest.json for bare minimum version (However, I recommend anything over 124.)
